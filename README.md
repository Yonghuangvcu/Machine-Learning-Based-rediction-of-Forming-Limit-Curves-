Project: Machine Learning-Based Prediction of Forming Limit Curves (FLC) in Sheet Metal Forming
Description: Contributed to a research initiative aimed at improving the prediction of Forming Limit Curves (FLC) using machine learning techniques. FLCs are critical in evaluating material formability and preventing failure in the sheet metal forming process. The project explores cost-effective and data-driven alternatives to traditional experimental methods like Nakajima tests, by utilizing tensile test data and predictive models.
Responsibilities:
•	Replaced Artificial Neural Network (ANN) models with optimized Random Forest algorithms for enhanced model interpretability and reduced training time.
•	Preprocessed and analyzed tensile test datasets, extracting mechanical properties such as yield strength, ultimate tensile strength, uniform and total elongation, strain hardening exponent, and anisotropy coefficient.
•	Built predictive models for both FLC₀ and full FLC curves using Random Forest Regressors and evaluated them against benchmark experimental results and empirical models.
•	Tuned hyperparameters through cross-validation to improve prediction accuracy and minimize overfitting.
•	Compared model outputs to experimental Nakajima test data and existing empirical formulas, demonstrating the reliability of Random Forest in predicting material behavior under forming conditions.
•	Documented findings for internal research publication and academic dissemination.
Environment: Python, scikit-learn, NumPy, Pandas, Matplotlib, Jupyter Notebook, Git, Windows/Linux.
